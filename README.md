# Financial Performance Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Financial Performance Dashboard built in Power BI using Microsoft's Financial Sample Dataset. The dashboard provides key business insights into sales, profit, profitability, discount impact, product performance, and regional performance to support data-driven decision making.

---

## 🎯 Objectives

- Monitor overall business performance
- Track Sales, Profit, and Profit Margin
- Analyze product and segment performance
- Evaluate discount impact on profitability
- Identify top-performing countries and products
- Build an executive-friendly interactive dashboard

---

## 🛠 Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Financial Sample Dataset

---

## 📊 Dashboard Features

### Page 1 – Executive Overview

- Total Sales KPI
- Total Profit KPI
- Profit Margin %
- Average Discount %
- Units Sold
- Monthly Sales & Profit Trend
- Sales by Country
- Sales by Segment
- Top Products
- Profit by Discount Band
- Interactive Filters

### Page 2 – Profitability Analysis

- Profit by Segment
- Sales vs Profit Distribution
- Profit Breakdown
- Decomposition Tree
- Product Ranking by Month
- Interactive Slicers

- Medium discount levels maintained stronger profitability.
- USA contributed the highest overall sales.
- Profitability varied significantly across business segments.
